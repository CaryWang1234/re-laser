# Re-Laser · 光路实验室

旋转镜面、规划光路，在回合上限内清除全部目标。30 个关卡分为基础教学、镜子操控、电力管理和综合挑战四章；全部关卡均有自动化通关回放验证。

```sh
npm install
npm run dev
```

打开终端显示的本机地址。`npm run build` 生成生产版本，`npm run preview` 预览构建。

## 玩法

- 点击带 ↻ 标记的镜子旋转；点击发射器切换普通 / 强力模式。调整不消耗回合。
- 普通激光消耗 1 点能量；强激光消耗 3 点，可以击穿蓝色装甲。能量不足时自动保留到下一回合。
- 每次执行，电池补充能量，所有具备足够电量的发射器发射。
- 光路预览显示下一回合实际发射结果，不改变局面。撤销会恢复操作、回合、电量和目标。
- 三星目标显示在右上角。通关纪录保存在本机浏览器。
- 空格执行，Z 撤销，P 预览，R 重试，H 帮助；方向键选格，Enter 操作。

## 创意工坊

选择工具后点击棋盘放置。重复点击发射器调整方向、镜子改变朝向、障碍切换普通 / 装甲。擦除工具删除单格。保存后可游玩、编辑、分享或导入关卡。验证器复用真实游戏规则；搜索达到预算会显示“搜索未完成”，不会错误宣称无解。

## 验证

```sh
npm test
npm run build
node scripts/browser-check.mjs
```

`npm test` 检查全部关卡的有效布局、三星通关回放、强光蓄能、完整撤销、预览无副作用、连续光路、验证器和导入数据。

浏览器检查使用本机 Chromium，可通过 `CHROME_PATH` 指定可执行文件。脚本临时启动本机静态服务，验证生产构建中的关键交互，并将桌面及手机截图保存到 `.checks/`；结束时关闭测试浏览器和服务。
