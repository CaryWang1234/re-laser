# Re-Laser · 光路实验室

旋转镜面、规划光路，在回合上限内清除全部目标。42 个关卡分为六章，其中「光电实验室」介绍新元件，「巨构回路」提供最大 20×16 的多阶段联动谜题。全部关卡均有自动化通关回放验证。

```sh
npm install
npm run dev
```

打开终端显示的本机地址。`npm run build` 生成生产版本，`npm run preview` 预览构建。

## 玩法

- 点击带 ↻ 标记的镜子旋转；点击发射器切换普通 / 强力模式。调整不消耗回合。
- 普通激光消耗 1 点能量；强激光消耗 3 点，可以击穿蓝色装甲。能量不足时自动保留到下一回合。
- 每次执行，电池补充能量，所有具备足够电量的发射器发射。
- 光路预览显示下一回合实际发射结果，不改变局面。撤销会恢复操作、回合、电量和目标。
- 三星目标显示在右上角。通关纪录保存在本机浏览器。
- 空格执行，Z 撤销，P 预览，R 重试，H 帮助；方向键选格，Enter 操作。
- 大棋盘支持滚轮、双指和 + / − 缩放，拖动平移；点击「全图」或按 0 复位。点选元件查看其规则和当前状态。

## 光电回路

| 元件 | 规则 |
| --- | --- |
| ϟ 转电器 | 吸收并终止光束；普通光产生 1 点电，强光产生 3 点电，容量最多 9 点。储能从下一回合开始供给相连的发射器，每个电源每回合向每个可达发射器最多传递 1 点。 |
| 金色导线 | 沿上下左右连接电池、转电器与发射器；激光可穿透。 |
| △ 散射器 | 保留激光强度，向前、向左、向右分出三路。环路按格子和方向去重，避免无限分光。 |
| 单圈传感器 | 本回合被照亮才激活，下一回合未被照亮则熄灭。 |
| 双圈记忆传感器 | 激活后保持，直到撤销或重置。 |
| 自动开关 / 光闸 | 读取上一回合的信号；同通道的所有传感器都激活才开启。`!` 代表反相开关，条件未满足时开启。 |
| 紫色传送门 | 同通道必须恰好两扇，传送光束并保留方向与强度。 |
| ▷ 单向光阀 | 只允许沿箭头方向传播的光通过。 |

每回合依次读取上一回合信号、传电、发射和分光、记录新电量与传感器状态。新产生的电和信号不会在同一回合连锁启动下游。通关需要清除全部障碍，并在同一回合使所有传感器激活；记忆传感器允许提前点亮。

六个联动挑战包含双区启动、信号同步、双钥 AND 逻辑、远端供能、反相时钟和多级核心重启。首页可以直接进入新章节。

## 创意工坊

选择工具后点击棋盘放置。重复点击发射器调整方向、镜子改变朝向、障碍切换普通 / 装甲。擦除工具删除单格。保存后可游玩、编辑、分享或导入关卡。验证器复用真实游戏规则；搜索达到预算会显示“搜索未完成”，不会错误宣称无解。

工坊支持全部光电元件、通道设置、最高 20×16 棋盘、回合与三星目标设置，以及不丢失编辑内容的试玩。重复点击传感器切换记忆，重复点击光闸切换反相；放置前选择通道，同通道传送门需成对。验证器对大型复杂关卡可能达到搜索预算，可使用试玩检查实际解法。

## 验证

```sh
npm test
npm run build
node scripts/browser-check.mjs
```

`npm test` 检查全部关卡的有效布局、三星通关回放、强光蓄能、完整撤销、预览无副作用、连续光路、验证器和导入数据。

浏览器检查使用本机 Chromium，可通过 `CHROME_PATH` 指定可执行文件。脚本临时启动本机静态服务，验证生产构建中的关键交互，并将桌面及手机截图保存到 `.checks/`；结束时关闭测试浏览器和服务。
